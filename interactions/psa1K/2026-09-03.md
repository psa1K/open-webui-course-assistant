## 采纳的决策与理由

| 决策 | 理由 |
|---|---|
| 采用 pip/uv 安装而非 Docker | 本机无 Docker 且无 sudo 权限 |
| 使用 Python 3.11 | 官方 README 明确建议 3.11 以避免兼容性问题 |
| 虚拟环境放仓库内 `.venv/` | 本地开发方便，且已加入 `.gitignore` 不入库 |
| 记录 `.webui_secret_key` 与数据库不入库 | 运行时敏感文件，避免泄露 |

## 遇到的问题与解决办法

- **安装超时**：`uv pip install` 首次超时（torch 等依赖较大）。改为后台执行、轮询日志确认完成。
- **Docker 不可用**：跳过 Docker 方案，改用官方 pip 安装路径。
