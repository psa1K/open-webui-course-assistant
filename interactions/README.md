# Agent 交互记录

本目录用于保留两位成员各自与 AI 编程 Agent（Codex / Claude / opencode 等）的交互记录，作为课程成果的一部分。

- 每位成员在 `interactions/<github-username>/` 下建立自己的目录
- 每人目录下**仅维护一个** Markdown 文件：`interactions.md`
- 记录内容：**每次交互**包含时间、Agent/模型、任务描述与 prompt、Agent 关键输出、采纳决策、问题与解决
- 每次交互按时间顺序追加，随代码一同提交

目录结构：

```
interactions/
├── psa1K/            # Jialiang Cai 的交互记录
│   └── interactions.md
└── eco-NIN/          # Yuzhe Guo 的交互记录
    └── interactions.md
```
