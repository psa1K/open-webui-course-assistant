# Agent 交互记录

本目录用于保留两位成员各自与 AI 编程 Agent（Codex / Claude / opencode 等）的交互记录，作为课程成果的一部分。

- 每位成员在 `interactions/<github-username>/` 下建立自己的子目录
- 文件按日期命名：`YYYY-MM-DD.md`
- 记录内容：任务描述、prompt、Agent 关键输出、采纳决策、问题与解决

目录结构：

```
interactions/
├── psa1K/    # Jialiang Cai 的交互记录
└── eco-NIN/  # Yuzhe Guo 的交互记录
```
