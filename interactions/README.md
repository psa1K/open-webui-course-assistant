# Agent 交互记录

本目录保留两位成员各自与 AI 编程 Agent 的交互记录，作为课程成果的一部分（题目要求提交"与 Codex 的交互记录"）。

## 约定

- 每位成员在 `interactions/<github-username>/` 下维护自己的目录
- 每人目录下**仅保留一个**文件：`interactions.md`
- **每次交互**按时间顺序追加，包含：
  - 时间
  - Agent/模型（如 psa1K 用 `opencode / DeepSeek-V4-Flash-0731`，eco-NIN 用 `Codex / GPT-5.4`）
  - 任务描述与 prompt
  - Agent 关键输出
  - 采纳/修改的决策与理由
  - 遇到的问题与解决办法
- 各自只追加自己的文件，互不覆盖
