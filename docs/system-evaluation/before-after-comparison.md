## 仍需改进的项目

1. **SYS-03**：补充或正确上传数学建模中 KMP 相关可检索材料；在无有效命中时不应在“资料来源”区列出无关 Codex 文件。
2. **SYS-05、SYS-14**：排查本机 Open WebUI 到模型或工具服务的 `HTTP 400: Server Connection Error`，确认第三方模型接入与先修关系工具的运行链路后，用相同固定用例复测。
3. **SYS-08**：将“资料不足”的拒答格式与验收规则进一步对齐，避免在无法支持结论时附带不必要的无关资料来源。
4. **SYS-11**：为 Codex CLI 练习题增加章节定向检索或元数据过滤，确保题目、知识点和来源都来自 CLI 资料，而不是仅主题相近的 Skill 文档。

以上为后续优化建议，不代表本轮继续实施新的配置变更；若要修改提示词、知识库、检索策略、工具或模型，须再次提出具体方案并取得用户批准。
