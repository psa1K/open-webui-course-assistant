## 1. 项目概述

本项目基于 [Open WebUI](https://github.com/open-webui/open-webui) 构建一门面向《Codex 实战课程》与《数学建模课程》的**课程专属 AI 助手**，综合利用 Open WebUI 的模型配置、系统提示词、知识库（RAG）与工具扩展能力，帮助学生进行**学习、复习与自测**。

系统由三部分组成：

1. **统一课程知识库**（`course-knowledge-base`）：收录两门课程共 18 份资料（Codex 实战课程 16 份 + 数学建模 2 份），支持检索增强生成（RAG）。
2. **课程 AI 助教**（`course-ai-assistant`）：绑定统一知识库，以「知识库优先、来源可溯、不确定即说明」为核心行为的智能体。
3. **七个自定义工具**：覆盖练习生成、随机抽题、客观判分、学习计划、章节查询、测试用例生成、先修关系查询，均可通过 Function Calling 在助教对话中被调用。

整个项目采用 **PR-merge 协作工作流**开发，全程记录与 AI 编码代理（opencode / Codex）的交互过程，具备可复现性与完善的自动化测试。

## 5. 功能模块详述

### 5.1 系统部署与模型接入（#14）

- 部署方式：Python 3.11 虚拟环境 + `uv pip install`（免 Docker、免 sudo），Open WebUI v0.11.3 运行于 `localhost:8080`。
- 模型：接入 DeepSeek API（OpenAI 兼容，`https://api.deepseek.com`），可用 `deepseek-v4-flash`、`deepseek-v4-pro`、`deepseek-v4-flash-vision-exp`。

### 5.2 课程知识库（#15）

- 结构：`knowledge/codex-course/`（14 个单元 Markdown + 1 PDF + 1 示例代码）+ `knowledge/math-modeling/`（Lecture1.pdf + LaTeX 源码）。
- 满足题目要求：18 份资料（≥8）、按章节分类、三类资料（课件/自编笔记/示例代码）。
- 单元 Markdown 由 `scripts/export_units.py` 从课程 HTML 自动拆分。

### 5.3 RAG 检索与引用（#16）

- 统一知识库 `course-knowledge-base` 收录两门课程全部资料。
- 首版参数：Top-K=5、相关性阈值 0.30、上下文保留完整段落、主要来源 ≤3（见 `configs/course-knowledge-base/rag-parameters.md`）。
- 行为约束：检索返回片段不等于有答案；低相关/无法支持结论时明确输出「资料中未找到相关信息」；不得编造引用（见 `citation-spec.md`）。
- 验收：`scripts/verify_rag.py` 在统一知识库上执行 6 类测试（直接问答、章节定位、跨资料综合、无答案、错误引用防护、引用格式），结果归档于 `docs/rag/verification-results.json`。

### 5.4 课程 AI 助教（#17）

- 模型 `course-ai-assistant`，底层 `deepseek-v4-flash`，绑定 `course-knowledge-base`。
- 系统提示词（`configs/course-assistant/system-prompt.md`）覆盖 8 项助教能力：知识库优先、结构化回答、来源引用、无答案处理、跨课程判断、学术诚信等。
- 配置与验收记录见 `configs/course-assistant/` 与 `docs/assistant/verification-results.json`。

### 5.5 自定义工具扩展（#18–#24）

共实现 **7 个 Workspace Tool**，每个均遵循「真实结构化逻辑（非提示词模拟）＋安装器校验＋单元测试＋配置文档＋Function Calling 验收」的统一交付模式：

| Tool ID | 功能 | 关键设计 | 测试 |
|---|---|---|---|
| `course_practice_generator` | 章节练习题临时生成 | 校验约束后返回结构化出题任务，由助教结合检索片段生成；不预置题库 | 20 |
| `random_question_picker` | 随机抽题 | 23 题真实题库（`question-bank.json`），seed 可复现，默认不含答案 | 18 |
| `objective_grader` | 客观题自动判分 | 真实结构化判分（单选/多选/填空/判断），字母/序号/文本三路规整，主观题标注需人工判分 | 25 |
| `study_plan_generator` | 学习计划生成 | 基于课程目录，按目标/时长/水平/偏好章节生成分阶段计划 | 14 |
| `course_catalog_query` | 课程章节查询 | 22 章结构化目录（`course-catalog.json`），确定性检索 + 四级相关性排序 | 20 |
| `test_case_generator` | 编程题测试用例生成 | 7 个内置算法模板 + 自定义参考解，**受限命名空间**运行参考解实算期望输出 | 23 |
| `knowledge_prerequisite_query` | 知识点先修关系查询 | 结构化先修关系（`knowledge-prerequisites.json`），直接/间接依赖与后续知识点 | 13 |

**工具安全设计**：`test_case_generator` 的自定义参考解在受限命名空间执行（仅暴露安全纯函数内建，无 `open`/`import`/`__import__`/`subprocess`）；各安装器统一校验工具源码不含网络/数据库/敏感配置依赖。

**数据资产**：
- `data/question-bank.json` — 23 题（codex 16 + math-modeling 7，三档难度、五种题型，每题标注来源文件与章节）
- `data/course-catalog.json` — 22 章（codex 16 + math-modeling 6，标题/类型/关键词/知识点/小节/来源位置）
- `data/knowledge-prerequisites.json` — 20 条知识点先修关系
