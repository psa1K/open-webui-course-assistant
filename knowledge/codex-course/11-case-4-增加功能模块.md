# Case 4：增加功能模块

用一个最小 REST API 串起 FastAPI 后端与前端信息展示。

## 目标

使用 Codex 完成一个简单的前后端联调功能、封装一个新功能开发的skill。

## 任务

- 设计一个**feature-development-workflow**的skill,把项目增加新功能的标准开发过程封装起来。 工作流： 1. 读取项目规则。 2. 分析需求和影响范围。 3. 定位相关文件。 4. 设计最小改动方案。 5. 先补测试用例。 6. 实现功能。 7. 运行回归测试。 8. 检查 diff。 9. 输出实现报告。

- 使用你的skill增加系统帮助文档展示的接口。

- 系统帮助文档可以使用case01生成的项目说明文档。

## 交付物

- skill打包文件。

- 后端接口和前端功能展示：包括API 接口说明和运行截图。

- 和Codex的交互过程。

建议用时**1小时**
