# Codex 的使用入口：App / CLI / IDE / Web 怎么选

> unit: unit-entry-points | type: source

## 一句话结论

Codex 可以通过 ChatGPT 桌面应用、CLI、IDE Extension、ChatGPT Web / Codex Cloud 与 Remote 使用。新手可从桌面端开始，终端工作流使用 CLI，编辑器内协作使用 IDE Extension，远程和后台任务使用 Web / Cloud 或 Remote。

### Codex 的使用入口

![图片标题为“Codex的4个入口怎么选”，介绍了Codex的4种使用入口：2.1 Codex App、2.2 Codex CLI、2.3 Codex IDE Extensio...](assets/source/dff6e172dad587.png)

如果你主要做本地项目、网页练习和日常开发，优先从 ChatGPT 桌面应用中的 Codex 模式 开始通常就够用；等你熟悉 Git、终端和团队协作后，再逐步补 CLI、IDE Extension、Web / Cloud 和 Remote。IDE Extension 当前还覆盖 Xcode 与 JetBrains 系列 IDE。
