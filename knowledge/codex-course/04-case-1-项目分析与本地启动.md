# Case 1：项目分析与本地启动

借助 Codex 快速读懂 Open WebUI，并让这套陌生代码库在本地跑起来。

## 目标

让学生使用 Codex 快速接手陌生代码库：[Open WebUI 开源项目 ↗](https://github.com/open-webui/open-webui)

## 任务

- 完成本地环境检查和项目启动。

- 使用 Codex 分析项目目录结构。

- 识别前端、后端和 SQLite 数据库位置。

- 生成项目架构说明。

- 记录启动过程中遇到的问题及解决过程。

## 交付物

- 成功运行的 Open WebUI。

- 项目说明文档，包括项目概述、技术栈和模块功能说明等。
