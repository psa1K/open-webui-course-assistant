# Case 3（可选）：增加一个快捷提示词功能

在聊天输入区加入三个清晰、实用且不会自动发送的快捷提示词。

## 目标

让学生使用 Codex 找到聊天输入框的实现，并在输入框上方增加 3 个可一键填充文本的快捷提示词按钮。

## 任务

- 使用 Codex 定位聊天输入组件及其文本状态。

- 增加“总结内容”：`请总结以下内容，并列出3个关键结论：`

- 增加“翻译为中文”：`请将以下内容翻译成中文，保持原意和专业术语准确：`

- 增加“优化表达”：`请优化以下内容的表达，使其更加清晰、简洁和专业：`

- 把对应提示词插入输入框开头，原有内容保留在下一行。

- 按钮只填充文本，不自动发送消息。

## 学生最终要实现的效果

1. 1**选择按钮**例如“总结内容”

1. 2**自动填入**提示词进入输入框

1. 3**补充内容**粘贴需要处理的文本

1. 4**手动发送**正常调用原有聊天功能

用户补充待处理内容，再手动发送。

## 交付物

- 显示 3 个按钮且可正确填充输入框的页面。

- 修改后的源代码。

- 按钮和填充结果截图，以及简要测试记录。
