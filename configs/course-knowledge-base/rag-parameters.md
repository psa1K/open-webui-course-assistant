# 统一课程知识库 RAG 首版参数

| 参数 | 首版值 | 说明 |
|---|---:|---|
| 检索模式 | 语义检索 | 使用 Open WebUI 知识库检索接口 |
| Top-K | 5 | 返回最多 5 个相关片段 |
| 最低相关性阈值 | 0.30 | 先以 0.30 作为起点，真实测试后再调优 |
| 上下文片段 | 完整相关段落 | 避免只截取孤立单句，保留必要上下文 |
| 单次主要来源上限 | 3 | 多文档问题最多列出 3 个主要来源 |

## 行为约束

- 每个回答至少引用 1 个实际命中的资料来源；无命中时不得生成伪引用。
- 引用要使用检索结果中的文件名和可确认的章节/片段。
- 后续应根据真实知识库测试结果调整 Top-K 和相关性阈值，不通过修改系统提示词掩盖检索问题。
