# 统一课程知识库 RAG 首版参数

统一知识库名称：`course-knowledge-base`，包含 `knowledge/codex-course/` 与 `knowledge/math-modeling/` 的全部资料，不拆分为两个 Knowledge。

| 参数 | 首版值 | 说明 |
|---|---:|---|
| 检索模式 | 知识库语义检索 | 使用 Open WebUI 的统一 Knowledge 检索接口；验收脚本固定关闭 hybrid，便于解释向量距离 |
| Top-K | `5` | 每个问题最多返回 5 个候选片段 |
| 最低相关性阈值 | `0.30` | 起始值；当前验收请求使用向量距离判定，`distance <= 0.30` 才通过阈值，距离越小越相关 |
| 上下文片段 | 完整相关段落 | 保留命中段落的必要上下文，避免只截取单句 |
| 多文档主要来源上限 | `3` | 最终回答最多列出 3 个主要文件 |

## 有效命中判定

“检索返回片段”不等于“找到答案”。验收脚本同时检查：

- 返回片段是否属于统一 Knowledge；
- `distances` 是否存在且达到 `0.30` 阈值；本脚本使用的向量检索接口中距离越小越相关；
- 片段内容或文件名是否与问题有可解释的主题重合；
- 片段是否足以支持最终回答和引用。

某些 Open WebUI 向量后端可能不返回 `distances`，此时脚本会记录“分数不可用”，只能依靠内容相关性作辅助判断，不能把缺失分数推断为高相关。低相关或无法支持结论的结果必须标记为无有效依据，并在回答中写“资料中未找到相关信息”。

## 调参原则

`0.30` 是真实知识库验证前的起始值。后续应根据 6 类最终回答测试中的命中质量、无答案误命中和引用准确性调整 Top-K/阈值；不能通过修改系统提示词掩盖检索质量问题，也不能为了让测试通过而伪造引用。
