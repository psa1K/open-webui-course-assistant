# 统一课程知识库引用规范

## 标准格式

回答末尾统一使用：

```text
资料来源：
- 文件：01-认识-codex-从代码补全到工程-agent.md
- 章节/片段：Codex 的定义与工程 Agent 能力
```

多个来源：

```text
资料来源：
1. 文件：06-codex-cli-安装与上手.md
   章节/片段：CLI 安装步骤
2. 文件：12-核心功能-mcp-与-git-github-工作流.md
   章节/片段：GitHub 工作流
```

无法确认具体章节时：

```text
资料来源：
- 文件：实际检索到的文件名
- 章节/片段：相关检索片段
```

## 规则

- 只引用本轮实际检索到且能够支持回答的文件；
- 低相关性或不能支持结论的结果不可引用；
- 无法确认章节时只能写“相关检索片段”，不得编造章节名；
- 引用示例代码时标明文件名和代码用途；
- 多文档问题最多列出 3 个主要来源，并区分 Codex 与数学建模内容；
- 知识库无相关内容时必须写“资料中未找到相关信息”，不生成伪引用；
- 用户要求引用不存在的文件或章节时，说明无法确认并拒绝伪造。

## 最终回答示例

```text
结论：Codex 可以通过 CLI、桌面应用、IDE 或 Web 等入口使用。

资料来源：
- 文件：02-codex-的使用入口-app-cli-ide-web-怎么选.md
- 章节/片段：Codex 使用入口对比
```

## 无命中示例

```text
结论：资料中未找到相关信息，无法依据当前统一课程知识库确认该外部事实。

资料来源：
- 本轮没有可支持该结论的有效检索来源，未生成文件引用。
```
