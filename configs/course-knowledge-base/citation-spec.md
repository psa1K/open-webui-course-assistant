# 统一课程知识库引用规范

回答末尾统一使用：

```text
资料来源：
- 文件：01-认识-codex-从代码补全到工程-agent.md
- 章节/片段：Codex 的定义与工程 Agent 能力
```

多个来源：

```text
资料来源：
1. 文件：06-codex-cli-安装与上手.md
   章节/片段：CLI 安装步骤
2. 文件：Lecture1.pdf
   章节/片段：相关检索片段
```

规则：

- 只引用实际检索到的文件；
- 无法确认章节时写“相关检索片段”；
- 引用示例代码时标明文件名和代码用途；
- 知识库无相关内容时不生成伪引用；
- Codex 与数学建模资料位于同一个知识库，引用必须保留真实文件名以区分来源。
